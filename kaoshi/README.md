# 在线考试系统

## 系统简介

基于 ThinkPHP 6.0 开发的在线考试系统，支持管理员端、教师端、学生端三种角色。

## 功能特性

### 管理员端
- 用户管理（学生、教师、管理员）
- 角色管理与权限配置
- 批量导入导出用户、批量生成账号
- 年级、班级管理
- 学科、章节、知识点管理

### 题库管理
- 支持题型：单选、多选、判断、填空、简答、主观题、图文题
- 按学科、章节、知识点、难度分类
- 批量导入Excel、Word格式文件
- 批量查重、试题审核

### 试卷管理
- 手动组卷：自主选题组卷
- 随机组卷：按知识点、难度抽题
- 试卷预览、复制
- 固定试卷、随机试卷

### 考试安排
- 创建考试，设置考试名称、时间、时长、满分、及格分
- 设置参考人员：按班级、年级、指定人员
- 考试规则：允许重考、交卷限制
- 定时发布、立即开始、延期考试

## 环境要求

- PHP >= 7.1
- MySQL >= 5.6
- Apache / Nginx
- Composer

## 安装步骤

### 1. 安装依赖
```bash
composer install
```

### 2. 配置数据库
编辑 `config/database.php` 文件，配置数据库连接信息

### 3. 导入数据库
执行 `database/install.sql` 文件到数据库

### 4. 配置Web服务器
设置网站根目录为 `public` 目录

### 5. 访问系统
默认管理员账号：admin / admin

## 目录结构

```
kaoshi/

│   ├── admin/             # 管理员端
│   ├── teacher/           # 教师端
│   ├── student/           # 学生端
│   └── common/            # 公共模块
│       └── model/         # 模型类
├── config/                # 配置文件
├── database/              # 数据库文件

│   ├── static/            # 静态资源
│   └── uploads/           # 上传目录
├── runtime/               # 运行时目录

```
