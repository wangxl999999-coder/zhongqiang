# BUG管理系统

一个简单易用的BUG管理系统，基于PHP + SQLite + Bootstrap开发。

## 功能特性

### 1. BUG上报和录入
- 快速提交表单包含标题、描述、重现步骤、严重程度、截图等
- 默认字段：创建人、创建时间、状态（待处理）
- 其他信息：版本号、所属模块、发现阶段

### 2. BUG状态流转功能
- 待处理 → 处理中 → 待验证 → 已关闭
- 每次状态变化记录操作人和操作时间

### 3. BUG分配与认领功能
- 管理员可以指派BUG给指定开发人员
- 开发人员可以主动领取未分配的BUG

### 4. 基础权限管理功能
- 管理员：配置项目、分配BUG、所有权限
- 开发人员：修改BUG状态、填写修改方案
- 测试人员：创建BUG、验证关闭

### 5. BUG查询和筛选功能
- 按状态、优先级、指派人、模块筛选
- 支持按标题搜索BUG

## 安装运行

### 环境要求
- PHP 7.0+
- PHP SQLite扩展

### 启动方式

1. 进入项目目录
2. 启动PHP内置服务器：

```bash
php -S localhost:8000
```

3. 在浏览器中访问：http://localhost:8000

## 使用说明

### 测试人员流程
1. 登录系统（使用 tester 账号）
2. 点击"上报BUG"创建新的BUG
3. 填写BUG详情并提交
4. 当BUG状态变为"待验证"时，测试人员可以验证并关闭BUG

### 开发人员流程
1. 登录系统（使用 developer 账号）
2. 在BUG列表中查看"未分配"的BUG
3. 进入BUG详情页，点击"认领此BUG"
4. 处理完成后，将状态改为"待验证"
5. 填写解决方案

### 管理员流程
1. 登录系统（使用 admin 账号）
2. 可以查看所有BUG
3. 将待处理的BUG分配给指定的开发人员
4. 可以管理用户账号（添加/删除用户）
